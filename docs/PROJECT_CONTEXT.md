## 边界

没有旧 API、数据库、云函数、管理后台或复制进仓库的 Provider 凭证。新增机票浏览器Worker只服务当前本地单并发API，不是任务队列或多用户服务。新后端复用用户 DSH 已有账户，当前模型路由 deepseek-account / deepseek-flash，三个角色的默认思考强度为 low/high/high，不覆盖输出上限。真实规划已验证，DSH通过现有CLI的航班查询已返回真实候选；独立航班搜索页已接真实工具，未做自动监控。仅显式未传入后端生成器的组件预览保留原1.1秒样例延时；两个正式入口默认传入真实生成器，失败不降级成样例。

H5通过Vite把/api转发到127.0.0.1:3000；小程序使用Taro.request。地图仍用OpenStreetMap/微信组件，真实生成的坐标无依据则留空，不借用样例坐标或图片。新后端当前是单机、单并发、无业务认证的验证环境，尚不支持公网、多用户、持久任务恢复、真实改行程或预订。
