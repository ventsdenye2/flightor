# FlightOR 路演设计

日期：2026-10-29。交付：原生单文件 HTML，12 页，16:9，中文，建议 5–7 分钟。

叙事：预算有限的年轻人 → 信息碎片与取舍 → 预算内体验价值 → Agent 工作流 → 预算示例 → 出行准备 → Harness → RAG → MVP → 博主合作 → 验证路线 → 邀请共创。

设计：天空 #EAF4FF、航线蓝 #1857E8、深海 #102C50、珊瑚 #FF7358、白 #FFFFFF。标题用系统黑体粗字，正文用微软雅黑，英文标识与数字用 Arial。大留白与非对称构图；封面以旅行路线插画为签名；预算用分段条，工作流用连接线，合作用路径结构，避免全篇卡片堆叠。原先图片型 PPT 技能不适用于用户指定的原生 HTML，按 HTML 交付优先。

事实口径：当前能力依据 PROJECT_CONTEXT、BACKEND_MVP；多平台聚合、专项政策核验、RAG 与博主合作作为设计/规划。博主名沿用用户提供的“行缘大姑妈”，不使用肖像、不宣称签约或授权完成。无融资金额、市场规模、用户增长或节省比例的虚构数据。预算为算术示例，无真实报价。

每页讲稿内置 HTML 的 notes 数据。演示无需网络、依赖或 API，不调用模型和供应商。
