# RAS：低预算航班与个性化旅行规划

日期：2026-09-20。状态：设计提案；本轮仅设计与开发计划，不实施业务代码。

## 产品目标

服务预算敏感、愿意灵活选择日期和中转地的旅行者。用户用自然语言描述想法，Agent 找到搜索范围内便宜且可接受的航班候选，解释取舍；用户采用后，围绕实际航段安排目的地与中转活动，并通过现有地图、图文与日程界面持续呈现结果。

“相对便宜”定义为：在公开的日期、机场、人数、舱位、行李及中转约束下，比较已检索到的有效候选。不承诺全球最低价。机票便宜与整趟旅行便宜分别展示；多住一夜或跨机场交通可能抵消票价节省。

用户旅程：说需求 → 确认必要条件 → 边搜索边反馈 → 比较推荐与备选 → 采用航班 → 逐步看到目的地/中转安排 → 地图与日程联动 → 自然语言修改 → 保存和恢复。

## 需求与验收

| ID | 行为 | 可观察验收标准 |
| --- | --- | --- |
| R01 自然交流 | Planner 自主理解与调用工具，按需追问 | 出发地/日期缺失时集中询问关键项；目的地开放时先推荐可搜索的候选；不要求用户填写完整表单，不用关键词规则替代语义理解 |
| R02 低价决策 | 灵活日期、同城机场、可接受中转的有界搜索 | 展示搜索范围、覆盖/失败日期、查询时间、币种、人数和费用缺项；候选去重；最低票价、少折腾、值得停留的代表方案可比较，方案不足时不凑数 |
| R03 航班先行 | 攻略绑定用户采用的真实报价或路线 | 已有 selection revision 为权威；查看详情不等于采用；换航班后旧任务不能写成当前攻略；采用不代表购票或锁价 |
| R04 中转可玩 | 依据可用时间与个人条件安排机场内或城市活动 | 160 分钟短转机不给城市游；有跨日停留的方案按独立中转访问安排；未知时区/入境条件/交通耗时不标成确定可执行；覆盖所有航段间隙 |
| R05 个性化 | 兴趣、节奏、人数、同行情况、行李与折腾容忍度参与决策 | 相同行程在“慢节奏美食”和“高强度博物馆”偏好下产生可解释差异；当前要求覆盖历史偏好；关闭 Memory 后不读取/写入；不推测敏感身份 |
| R06 等待体验 | 真实执行进度、阶段成果、取消和恢复 | 显示正在比较哪些日期、已获得多少方案/哪些日程已保存及来源；不显示内部思维链、伪造百分比或无依据剩余时间；失败保留可用成果 |
| R07 图文地图 | 复用现有 UI，接入真实活动位置和素材 | 点日程聚焦相应地点、点地图显示同一活动；无坐标不落假图钉、无照片有明确占位；航线示意和城市交通路线区分 |
| R08 修改与一致性 | 修改预算/日期/兴趣/航班，产生新版本 | 同一 Trip 内可恢复；过期结果明确标识；账号隔离；只复用领域规则判定兼容的证据，不重写历史 Artifact |
| R09 可信交付 | 服务器判断完成程度 | 研究成功而攻略未保存时不能显示完成；来源失效、限流、部分覆盖和价格过期可见；日程冲突不能靠降低完成标准绕过 |

## 首版范围及假设

- 保留现有四个主 Tab 和蓝色视觉基线，不重做 UI 视觉设计。
- 优先一个出发地、一个最终目的地、单程含中转的完整闭环；研究/游玩攻略可包含多个停留点。现有普通往返机票检索能力保留，不等于自建路线引擎已支持往返组合。
- 默认 Agent 推荐，用户显式采用航班；不自动替用户选择第一条。若以后要求 Agent 自动采用，需要独立授权契约。
- “世界穷游”作为产品方向，首发对已验证的机场与数据覆盖范围负责；开放目的地跨国搜索、拆票多日停留和往返优化逐步扩展。
- 不做购票、支付、自动签证资格判定；入境条件只记录来源、核实时间、适用条件和待确认状态。

## 体验目标（待实测校准，不是当前成绩）

| 指标 | 首期目标 | 测量方式 |
| --- | --- | --- |
| 输入反馈 | 点击后本地 300ms 内出现已提交状态 | 小程序端埋点 |
| 服务端接单 | 正常网络 P95 ≤ 2 秒，返回可恢复 turnId | 从提交到有效回执，单列弱网样本 |
| 首份可用内容 | 航班候选或有事实支撑的阶段结果 P50 ≤ 15 秒、P95 ≤ 30 秒 | 从接单到首个 Artifact 可见，缓存命中/未命中分别统计 |
| 活动反馈 | 状态改变后前台下一次轮询展示，轮询目标间隔 2–3 秒 | 真实事件时间到渲染时间；心跳只证明存活 |
| 攻略等待 | 30 秒内尽量呈现首个可用日程；60 秒仍未完整时提供保留结果、继续等待、取消入口 | 超时与供应商失败纳入样本，不只统计成功请求 |

先建立基线，再以固定回归案例和标注并发量的小批真实请求校准分位数；样本不足时只报告样本数和范围。300 秒仅为已有保护上限，不是用户应等待的默认时长。无法达到时缩小首批搜索/研究范围并诚实展示部分结果，不用动画掩盖。
