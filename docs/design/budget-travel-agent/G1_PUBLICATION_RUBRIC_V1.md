# G1 发布合同 v1（冻结 2026-09-21）

依据用户对独立诊断的实施授权，采纳 [ADR 0024](../../adr/0024-guide-publication-contract.md)。本版本取代继续逐样本追加隐含内容门槛的做法，不修改历史报告结论。后续调整必须增版说明原因。

| ID | 硬要求 | 允许降级 |
| --- | --- | --- |
| P1 | 两个入口保存、领域验收、独立请求恢复；owner/context/航班与取消边界保留 | 未测入口/平台明确未测 |
| P2 | 卡片、回复和恢复均不得发布模型新增的高影响事实或预算承诺；title/theme/notes 等不能旁路 | 费用、开放时间、预约和交通耗时明确未知 |
| P3 | 摘录绑定来源与快照；错误 quote/hash 不作为证据；来源冲突不静默升级为适用 | 来源标题/原文以明确引用显示，不宣称主体或未来适用已核实 |
| P4 | 预算目标与成本判断分开；未知不等于零、未知费用不排除 | 无账本 assessment=undetermined，小计 null |
| P5 | 至少保留每天可识别的建议去处/时段及所要求的实用参考，且真实符合日期和偏好 | 某些具体费用未知；不能以全占位空攻略通过 |
| P6 | 旧 Artifact/关联历史回复可恢复，原始记录可审计 | 旧未审查文字不作为当前结论，明确有限展示 |

离线冻结矩阵：正确及错误证据；省略/空 claim 但散文有票价；title/theme/notes 中无数字的“免费/无需预约”；403/缺正文；同对象冲突；有来源但适用性未知；预算缺项且声称满足；保存后新增事实/英文元叙述；旧版及错 artifact/version/revision；提前卡片和恢复一致；混合/未完成目标不提前结束；取消/外 owner/过期 generation 不发布。

退出：离线对抗回归通过后，另获额度的固定双入口真实批次与声明范围内的平台展示/恢复烟测通过，才可关闭相应 G1 层。两个入口各一次只是烟测，不证明可靠率。全部失败记录保留。当前修复无新的付费授权，不能因离线通过宣称 G1 完整通过。

M2 负责个性化深度、文笔、更多城市覆盖和估算质量；P5 的最低可用性依然属于 G1，不通过降低实用性消除错误。正式 M1 仍依赖 G1；允许先准备离线测量材料。
