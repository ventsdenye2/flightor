## 命令

在独立worktree的backend目录执行，明确指定本机基础配置路径，不自动猜测父目录。脚本叠加该worktree的`.env.dsh.local`；不要输出两个环境文件或私密DB交接JSON的内容。

```powershell
$env:FLIGHTOR_BASE_ENV_PATH = 'D:\FunnyProject\flightor-repo\backend\.env'
node scripts/verify-dsh-live.mjs --dry-run --case A
node scripts/verify-dsh-live.mjs --dry-run --case B
```

默认dry-run不连接DB、不写批次state、不启动worker、不请求Provider。它显示当前配置路由、是否已有账本、剩余判断所需的累积记录和冻结问法；有Key不等于获准真实执行。

主任务核对本次明确授权与预算/凭证后，先构建，再顺序运行：

```powershell
npm run build
node scripts/verify-dsh-live.mjs --execute --case A
node scripts/verify-dsh-live.mjs --execute --case B --serve
```

当前批次围栏固定为2美元、48模型调用、12搜索调用；脚本同时要求`.env.dsh.local`这些配置值匹配。它不是未来的新授权，也不能通过修改配置或目录重置预算。官方搜索`deepseek-official`使用明确独立Key与`https://api.deepseek.com/anthropic/v1`配置，缺少条件时不降级替代；实际官方调用是否成功须看运行回执。

`DSH_DB_ENV_PATH`可指定凭证交接位置，默认忽略文件`backend/.demo/dsh-db-env.json`的`TEST_DATABASE_URL`字段，必须loopback且不预设search_path。代码只新建/复用本轮`dsh_live_20260924`并迁移该schema；数据库连接、口令不输出。首次创建后保留数据，不清理schema，不对public业务表迁移；001迁移可能建立共享pg_trgm扩展，这不是生产业务写入。

## 恢复、UI与失败

固定输出为`backend/.demo/dsh-live-20260924/`。state保存测试Trip/会话/状态/冻结日期及模型和搜索路由；report累积每次执行，不覆盖失败记录。预算使用应用既有`backend/.dsh-data/budget.json`，如显式配置其他路径则冻结并要求后续一致，永远不自动创建另一个额度池。runner.lock只防该runner并发，已存在时停止检查，不自动删锁；DSH费用账本另有自己的写入锁。

某例失败或执行中断后，后续`--execute`拒绝重新发送该例。不能修改问法继续跑到通过；应保留失败、诊断修复，再由主任务明确决定后续验证。未开始的另一例可以用`--case B`独立运行，仍共用预算。已通过例再次execute只GET恢复，不重新发模型。可使用`--serve --case A`或`--serve --case B`只启服务/恢复读取，不触发模型；默认loopback端口3024，`DSH_LIVE_PORT`可显式调整。

`--serve`结束验证后保持app运行，供正式H5使用。忽略的`transport.private.json`给出baseUrl、各例Trip/conversation、测试token；只能供本地浏览器自动化接入，不提交或展示。UI写请求缺少仅runner内存持有的nonce时返回403，刷新/切语言/详情GET可读取已保存结果，不能意外启动付费规划或补图。SIGINT/SIGTERM关闭app/worker和连接池并释放本runner锁，保留数据库和账本。
