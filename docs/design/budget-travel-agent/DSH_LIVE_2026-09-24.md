### E2E 实时执行观测辅助脚本

`backend/scripts/dsh-e2e-observation.mjs` 是验收 runner 的只观察辅助模块，不是产品执行底座。`installDshE2eObservation({directory,dataDirectory})` 在 dry-run 提前退出之后、第一次真实 DSH manager 调用之前安装。两个参数均为可信绝对目录；它动态导入编译后的 `DshSessionManager.prototype.run`，同路径重复安装幂等，不支持改路径重装。生产源码、配置、预算和 Agent Loop 不变。

每次 run 在 `<directory>/executions/<随机executionId>.jsonl` 创建独立文件（请求0700目录、0600文件权限），同一执行始终追加，不覆盖旧记录。每一条在事件发生时同步写入，执行结束后同步flush/关闭，无需等待runner正常退出即可读取已写事件。新文件无法打开时在调用底层run之前失败；执行期间日志写入故障只增加返回handle的 `writeFailures`，不覆盖底层业务返回或异常。验收须检查该值，不能将不完整观测宣称完整。

允许记录的字段固定为：执行/代次/Trip/会话身份、时间与相对耗时；model/tool活动及toolCallId；commit的baseGuideId/expectedContentHash/replaceSlots、接纳状态/Artifact/内容hash/完成状态与有限错误code；计量admit/receipt的id、token数字（含reasoning token计数）、finishReason、model、maxTokens、thinking、failed与duration；web回执的evidenceRefs/URL/HTTP状态；最终reason/calls/resumed/rehydrated/cancelled。finally只按manager相同的SHA256(owner,Trip,conversation)定位映射文件，记录规范UUID sessionId及profile/epochHash，缺失映射单独标记。

不记录用户消息、snapshot、persona、模型自由回复、原始CoT、工具全文、页面正文、搜索query、HTTP头、密钥或原异常message/stack。错误只提取有限code，带冒号的详细说明丢弃；URL拒绝嵌入用户名密码并去掉query/fragment，避免签名/访问token进入日志。模型写入success字样不能成为通过依据；自动PASS仍须runner核对实际领域publication/Goal和费用回执。预算准入和结算仍全部由原来的 `budget.admit/settle` 负责；observer不发网络请求、不修改费用账本。

返回handle包含实际executions目录、dataDirectory、累计writeFailures和uninstall。runner安装后，内部probe以及正式H5触发的实际DSH run都被覆盖。onActivity、execute入参/返回/异常和run结果原样传递；模块不阻止或增加任何模型/工具调用。它不涵盖独立显式本地化客户端，后者仍以原费用账本的localize回执为准。
