# ADR 0022：引用资料的适用性独立于来源核验

2026-09-21。已实现，验证证据见 [progress](../design/budget-travel-agent/progress.md)；不是 G1 已通过的声明。

## 问题与决策

[G1 追加复验](../design/budget-travel-agent/G1_RETEST_2026-09-20.md) 暴露有来源的旧票价被复述为当前事实。来源可信度、抓取 checkedAt、缓存 expiresAt、查询旅行窗口均不证明具体价格或营业时间在出行日生效。当前研究适配器没有可执行的逐项有效期证明，因此不能新增一个由模型自报的“当前已核实”状态。

攻略领域为每条日程引用和 supportingEvidence 写入 `sourceApplicability={status:reference_only,notice:固定说明}`。说明明确本摘要中的价格、开放时间和交通时长，其当前及出行日适用性尚未核实，应以运营方届时公告为准。原摘要、来源、verification 原样保留；不覆盖旧数字、不因旅游局来源或新 checkedAt 升级为当前报价。引用的约数可作为资料参考，不能被当成该次门到门衔接保证。

`travel-guides/source-applicability.ts` 是服务端生成及解释权威。新 authored builder 为 `agent-authored-guide-v3`，确定性 builder 为 `travel-guide-v3`。保存和 durable verifier 共用 validateGuideContent，要求新 builder 的每条引用具有精确的 reference_only 契约；删掉说明或改成已核实不能通过。该字段不由 Planner 输入。预算快照门槛继续覆盖 authored v2/v3。

预装研究逐条携带同一只读说明；read_artifact 对旧攻略缺失字段添加只读引用投影，不改存储或验证结果。Planner 指令要求在规划备注和最终复述中保持适用性限制；遇到来源冲突要说明或省略争议数字。提示词并不构成散文语义自动验证。最终答复应直接面向用户，不输出英文内部元叙述。

客户端在各引用摘要旁展示说明，旧资料或不支持的标记同样按当前适用性未知显示；不把“来源已核验”当作价格有效。中文客户端文案与服务端契约一致，资料正文不被篡改。

## 兼容、范围与回滚

这是 v1 攻略可选字段扩展；旧记录不迁移，仍可读取并按旧持久合同验收，**不追认其时效质量通过**。客户端旧记录回退仅是展示，不改存储。旧严格 schema 二进制可能无法读取新增字段，不能宣称直接无损回滚。Research schema、数据库、Provider、模型、Goal 约束和默认关闭的 lean 开关未变。

这一步建立明确的引用边界，**没有实现运营方正文复核、冲突发现、逐项报价更新或任意散文事实检测**。当前不能把未知改成已知，不能用附注把已发现错误的事实宣称为已纠正。完整 G1 仍需真实内容复验及平台验收；进一步引入已核实状态须有绑定具体声明、来源正文、有效区间与旅行日期的领域合同，不能从 checkedAt 推导。

## 验证要求

新鲜且 verified 的研究仍为 reference_only；日程与补充资料均保留原文；去除/篡改适用性被拒；旧记录可读；预算门槛与活动日期门槛不退化；客户端旧/新/恶意标记均不展示为当前已知。测试结果、运行耗时及未运行项见 progress。
