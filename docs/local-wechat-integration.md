# 当前集成版：微信开发者工具本地测试

2026-09-13，工作分支 `codex/production-integration`。

## 打开项目

在微信开发者工具导入目录：

```text
D:\FunnyProject\flightor-repo\.worktrees\production-integration
```

根目录 `project.config.json` 的 `miniprogramRoot` 指向 `dist/`，这是仓库唯一的微信小程序编译目录，连接真实本地 API。请始终从仓库根目录导入项目。

当前 API 为 `http://127.0.0.1:3011`，PostgreSQL 为 `127.0.0.1:15432`，数据库 `flightor_integration_20260913`。现有 API 和数据库继续运行，无须重复启动。网页入口为 `http://127.0.0.1:4179/live.html#/pages/plan/index`。

从上述项目目录生成最新小程序：

```powershell
npm run build:weapp:local
# 持续修改前端时可以改用：
npm run build:weapp:local -- --watch
```

构建读取忽略的 `backend/.env.demo`，注入本机 API 和本地测试登录配置。该构建用于本机模拟器；不适用于上传发布或手机直接访问 localhost。

开发工具中点击「编译」，进入底部「规划」。如需登录，打开「我的」或「经典规划」的登录入口，使用「本地测试登录」。它与网页使用同一个本地测试账号和数据库，但两端各自保存登录状态；无需重新调用模型即可读取已有行程。

## 为什么之前只有规划页是新版

新版设计分支 `codex/ui-experience` 的代码此前已合入当前集成分支，但正式业务入口当时只接入了 `PlannerPage` 和行程详情 `TripExperience`。样稿中的探索、行程列表、个人页和航班页虽然已经存在，正式 tab 与页面路由仍指向原业务页面。因此“设计代码已合入”和“所有业务页面已换上新版 UI”是两件尚未同时完成的事。

本轮补齐正式入口，继续使用真实 API、数据库与已有 stores；没有将 `AppExperience` 的会话内演示状态充当真实账户或保存结果。

| 页面 | 本轮接入范围与数据来源 |
| --- | --- |
| 规划、行程详情 | 保留真实对话、已保存攻略和继续修改入口；回复排版、阶段显示与结果卡片使用新版组件 |
| 探索 | 新版灵感卡片与空态，读取后端已发布内容；不自动填入里斯本等固定样例 |
| 我的行程 | 新版列表、状态筛选、分页、归档/恢复、对话与结果面板；使用真实云端行程和会话 ID |
| 我的、旅行偏好 | 新版账户、快捷入口与设置；保留真实登录/退出、语言切换和云端偏好编辑器，内部切页保留未保存草稿 |
| 航班搜索、搜索结果 | 新版表单和航班展示；继续走已有真实搜索与结果数据，不使用样稿票价 |
| 价格提醒、关于 | 统一新版视觉；目标价保存在本机，关于页按实际云端数据范围说明 |
| 底部导航 | 四个主 tab 共用新版白色导航，切换仍使用正式页面路由；网页测试与微信小程序保持一致 |

当前本地数据库在本轮检查时没有 `published` 灵感，所以探索页显示“暂时还没有旅行灵感”的空态是预期数据状态。以下情况也不能单凭视觉判断为“仍是旧版”：

- 真实行程暂未提供照片时，不补入固定旅游图片；页面保留已有文字、日期、活动及来源。
- 样稿中的灵感收藏与行程书签尚未接入真实收藏持久化，不能把预览中点亮的书签当作已同步收藏。真实行程、路线保存与对话恢复仍使用已有业务保存能力。
- 价格提醒当前只保存本机目标价，尚未实现自动查价与推送；页面明确显示这一状态。没有搜索参数时，不再预填 PVG→LHR 或伪造“当前价 5000 元”。

## 回复与工作状态显示

- 网页与微信小程序共用 Taro 页面，之前两端都直接用 Text 显示回复原文。现在新版规划与经典规划使用原生 View/Text 排版段落、标题、列表、粗体及代码；不执行原文中的 HTML 或脚本。
- 已保存的行程卡片位于完整回复前，点击「查看行程」查看每日活动。不再为空封面显示大块图片占位；没有真实图片、报价或坐标的数据仍不凭空补齐。
- 工作时只显示最新一条后端活动阶段，以及连接状态和等待秒数。阶段来自真实工具执行状态；不是模型内部推理原文。结束后移除，组件卸载或停止时清理计时器，不写入聊天消息、模型上下文或持久化存储。断联时明确显示正在重连与最近确认的阶段。

## 仍看到混合新旧页面时

1. 确认开发工具当前导入的是仓库根目录，项目配置仍指向 `dist/`。仓库不再保留独立样稿小程序入口。
2. 在该目录运行 `npm run build:weapp:local`，等待构建成功；避免另一个普通 `build:weapp` 或样稿 watch 任务随后覆盖产物。
3. 在微信开发者工具「清缓存」菜单中只选择「清除编译缓存」，然后重新「编译」。不要选择「清除全部缓存」或清除 Storage/数据缓存；这些操作会影响本地登录、会话恢复及本机目标价。
4. 如仍显示旧产物，关闭并重新打开同一个项目，再编译；保留项目数据和既有数据库，不通过清库或退出登录解决样式缓存问题。
5. 网页测试确认打开 `http://127.0.0.1:4179/live.html`，使用强制刷新（Ctrl+Shift+R）重新加载前端资源；不要清除站点数据、localStorage 或登录信息。

刷新后先进入「我的行程」读取已有记录，以确认账户与恢复路径仍正常，再继续新一轮对话测试。
