# 对话中的航班选项

2026-10-19界面精简：按用户截图移除列表底部的来源/查询时间/报价快照说明、通用推荐说明和“查看查询来源”入口。来源与查询时间仍保留在后端记录和数据字段，卡片继续展示航班事实和逐条推荐理由；设计预览保留卡片上的样例标识。双端共用该组件。

MVP 不增加 verifier、审查Agent、发布门槛或完整度要求。信息缺少照常展示、交流和规划；推荐理由是前端对已取得事实的简短比较。本批回归脚本仅供开发验证，不参与用户请求处理或阻止输出。

回归覆盖同币种票价/时长排序、未知值不当优势、跨日、CLI字段原样映射、原始证据不外泄、选择/刷新/聊天/清除均不规划，以及显式规划保留候选和完整聊天上下文。使用假Agent，不调用付费模型。构建与浏览器结果见下方各批验证记录，提交前本地复验见[BACKEND_MVP](BACKEND_MVP.md)。

H5 状态场景提供“查看机票选项设计”，使用明确标识的设计样例，无需发起新的收费模型或机票查询。真实入口仍是规划页中查询后的卡片。已选航班仅有摘要时，行程卡保留真实摘要起降时间，不伪造详细航段。

也可直接打开 `http://127.0.0.1:4178/?view=flight-options` 预览选项设计。规划中新取得的航班证据随本对话保存，后续聊天不会退回旧一轮结果。
完成状态的首次轮询已带本轮航班选项，不需要再次刷新才显示。

本批验证：双端类型检查、H5构建、小程序构建、前端回归与12项后端回归通过。Playwright模拟API验证了选择不创建run、刷新保留、选后继续聊天、清除不规划、详情未知项、排序/展开、明确按钮规划携带选定信息，以及320/390/1440宽度无横向溢出。本轮未调用真实付费模型、未重查供应商，未做微信真机验收；沿用现有查询CLI。

更新：2026-10-19。规划页把本轮 CLI 查询快照中的候选航班作为可选卡片展示，保留自然交流，选择后由用户主动启动行程规划。

对话公开字段 `flightOptions` 只包含查询时间、来源、航线、日期、候选票价/航司/机场/当地时刻/航段/中转/行李；不返回原始工具消息或本地证据路径。旧对话从自身工具证据恢复，不能从无关查询目录随意取报价。

提交可选 `flightSelection: { searchId, candidateId }`，服务端匹配本对话真实候选，将选中快照作为规划约束，审核后的展示保持同一候选。普通聊天不因选择而自动生成。新查询建立新的选项组，旧消息中的选项和选择仍保留；当前选择不自动移到新组。此校验只防止错配航班，不限制资料不足时生成行程。

`POST /api/conversations/:id/flight-selection` 只保存选择（`selection` 可为 null 以清除），不创建 run，不调用 DSH，也不触发规划。刷新从对话恢复。用户选择后仍可聊天；只有点击生成行程或自然语言明确要求开始规划才生成。运行中暂不改变选择以避免覆盖当前对话。

规划页把`flightOptions`附着在首次返回它的助手消息，新消息依次显示在它下方。选择在后端静默保存，仅卡片边框、勾选与“已选这班”反馈；不弹窗、不新增保存提示条。尚未发下一条消息前可更换或取消；选定后继续聊天或点击规划即锁定，卡片与详情都不能再切换，刷新仍锁定。可以在后续聊天中查询新组选项。行程结果同样附着在规划消息并保存，刷新或继续聊天不会丢失查看入口。“生成行程”仍只由明确点击或表达开始规划触发。独立设计预览没有后续聊天，保持本地可选。

共享组件 `FlightChoices` 提供推荐/价格/用时排序、前三项与展开全部、单选状态及航段详情。每张卡片展示当地起降时刻、跨日标记、机场代码、航司、总时长、中转次数、币种和每成人报价。推荐理由从本次候选的同币种价格、用时、中转事实计算，不虚构模型意见或“全网最低”；未知行李/保障不算作优势。详情列出航班号、中转、换机场、行李和退改签待确认项。
